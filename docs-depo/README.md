# docs-depo

Developer-facing storage: development-process notes, team deliverables, and reference material. Not read by code. Not a public README.

- `setup.md` — install, run, test, pre-commit. Dev-facing reminder, not onboarding.
- `pitch/` — pitch decks and proposal deliverables.
- `demo-data/` — frozen copies of external spec and requirements documents.
- `exploration/` — research notes on anything that could inform a build decision: OSS tools, dependencies, vendor services, architecture studies.
- `plans/` — development process workflows. Runbooks for common dev tasks (finalizing PRs, onboarding, release checklists). Longer-form than a README, meant to be followed step-by-step by a human or an agent.

If a new piece of material doesn't fit one of these, add a new subfolder with its own one-paragraph README — don't dump loose files at this level.
