# docs-depo

Everything non-webapp. Not read by code. Not an onboarding doc.

- `pitch/` — pitch decks and proposal artifacts.
- `demo-data/` — frozen copies of external spec and requirements documents used for demos.
- `exploration/` — research notes on anything that could inform a build decision: third-party OSS tools, dependencies, vendor services, architecture studies. Scouting and decided-on both live here.

If a new piece of material doesn't fit one of these, add a new subfolder with its own one-paragraph README — don't dump loose files at this level.
